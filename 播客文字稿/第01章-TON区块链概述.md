## 第一部分：TON是什么？

好，我们先从最基础的问题开始：TON到底是什么？

TON的全称是The Open Network，翻译成中文就是"开放网络"。它是一个高性能的区块链平台，最初是由Telegram团队设计的，对，就是那个有9亿用户的即时通讯软件Telegram。

### TON的历史故事

说到TON的历史，还挺有意思的。这个故事要从2018年说起。

2018年，Telegram发布了TON的白皮书，计划在区块链领域大展拳脚。2019年，他们通过ICO，也就是首次代币发行，筹集了17亿美元。这在当时可是轰动一时的大新闻。

但是，故事在这里出现了转折。2020年5月，美国证券交易委员会，也就是SEC，起诉了Telegram，说他们的代币发行涉嫌违规。结果，Telegram被迫在2020年6月宣布停止TON的开发。

很多人以为这个项目就这样结束了。但是，区块链社区的力量是强大的。2020年，一群开发者接管了这个项目，把它改名为The Open Network，继续开发。这就是TON的第二次生命。

2021年，TON主网正式上线。2022年，生态开始快速发展，各种DeFi项目、NFT项目纷纷出现。2023年，Telegram创始人Pavel Durov重新公开支持TON，还在Telegram里集成了TON钱包。到了2024年和2025年，TON生态全面爆发，特别是Mini Apps生态，发展得特别快。

### TON的核心设计理念

那TON和其他区块链相比，有什么特别之处呢？TON主要解决了传统区块链面临的"不可能三角"问题。

什么是"不可能三角"？就是说一个区块链很难同时做到去中心化、安全性和可扩展性这三点。通常你只能选其中两个。

TON是怎么解决这个问题的呢？它有三个核心设计理念：

**第一，高吞吐量。** TON的处理速度非常快，每秒可以处理超过10万笔交易。相比之下，比特币每秒只能处理7笔，以太坊每秒15到30笔，就算是Solana，每秒也就6.5万笔左右。TON的速度是这些主流区块链的几倍甚至上千倍。

**第二，无限扩展。** TON采用了动态分片技术。简单来说，就是当网络负载增加时，TON可以自动增加分片的数量来分担压力。这就像是一家餐厅，客人多了就自动增加服务员和桌子，不会出现排队等位的情况。

**第三，异步执行。** 传统的区块链，比如以太坊，采用的是同步执行模式。A调用B，B调用C，C调用D，必须一步一步按顺序来。TON采用的是异步消息模型，A可以同时给B、C、D发消息，不用等一个完成再做下一个。这就像是你发微信，可以同时给多个人发消息，不用等第一个人回复了再给第二个人发。

### TON与其他区块链的对比

我们来具体对比一下TON和其他主流区块链。

从共识机制来看，TON采用的是PoS加BFT，也就是权益证明加拜占庭容错。以太坊也是PoS，Solana用的是PoH加PoS。

从TPS，也就是每秒交易数来看，TON超过10万，以太坊15到30，Solana大概6.5万。

从出块时间来看，TON大约5秒出一个块，以太坊12秒，Solana最快，400毫秒。

从交易费用来看，TON非常便宜，大概0.001到0.01个TON。以太坊就贵多了，1到50美元不等。Solana也很便宜，大概0.001美元。

从智能合约语言来看，TON有Tolk、Tact、FunC三种语言，以太坊主要是Solidity，Solana用Rust和C。

从账户模型来看，TON是基于Cell的，这个我们后面会详细讲。以太坊和Solana都是基于账户的。

从消息模型来看，TON是异步的，以太坊和Solana是同步的。

从分片技术来看，TON有动态分片，以太坊计划分片但还没完全实现，Solana没有分片。

那TON有什么独特优势呢？

首先，Telegram集成。Telegram有9亿用户，这是TON的天然流量入口。

其次，用户友好。TON的地址可以用.ton域名，就像网站域名一样好记。而且Gas费用低且稳定。

第三，开发者友好。TON有现代化的合约语言，工具链也很完善。

第四，可扩展性。动态分片让TON真正实现了无限扩展。

## 第二部分：TON生态全景

了解了TON的基本情况，我们再来看看TON的生态都有哪些内容。

### 主流钱包

首先是钱包。钱包是你使用TON的入口，就像你要用钱得先有个钱包一样。

TON生态有好几款主流钱包：

**Tonkeeper**，这是最常用的钱包，有移动端和桌面端，用户界面很友好，还支持dApp。

**MyTonWallet**，这是网页版和浏览器扩展版，功能很丰富，而且是开源的，很多开发者喜欢用。

**Tonhub**，移动端钱包，安全性很高，适合存放大额资产。

**Telegram Wallet**，这是Telegram内置的钱包，最大的优点是不用安装，直接在Telegram里就能用，特别适合新手入门。

**Ledger**，这是硬件钱包，安全性最高，适合长期持有大量资产。

那怎么选择呢？如果你是新手，推荐用Telegram Wallet，最简单。日常用推荐Tonkeeper，功能全面。开发者推荐MyTonWallet。如果资产比较多，推荐Ledger加上Tonkeeper的组合。

### DeFi协议

接下来是DeFi，也就是去中心化金融。

**DEX，去中心化交易所**，TON上有几个主要的：

STON.fi，这是TON原生的AMM，也就是自动做市商，滑点很低，TVL超过5亿美元。

DeDust，支持多链桥接，流动性很高，TVL超过3亿美元。

Megaton Finance，这是跨链桥加DEX的组合，TVL大约1亿美元。

**流动性质押**，就是把你的TON质押起来赚收益，同时还能拿到一个流动性质押代币，可以继续在其他地方使用。

Tonstakers是最大的LST协议，年化收益大概4%到5%。

bemo也是做流动性质押的，年化收益大概4%。

**借贷协议**，目前TON上主要是Evaa Protocol，这是TON上首个借贷协议。

### NFT与数字收藏品

NFT在TON上也很活跃。

Getgems是TON最大的NFT市场。

Fragment是Telegram官方的平台，主要交易Telegram的用户名和电话号码。

TON Diamonds是高端的NFT收藏品平台。

TON的NFT有几个特点：Gas费用很低，大概0.01到0.05个TON；可以和Telegram头像集成；支持版税，创作者可以持续获得收益。

### Telegram Mini Apps

这是TON生态最有特色的部分。Mini Apps是运行在Telegram里的轻量级Web应用，可以直接和TON区块链交互。

用户流程是这样的：打开Telegram，找到Mini App，用TON Connect连接钱包，然后就可以和智能合约交互了。

有几个热门的Mini Apps：

Hamster Kombat，这是一个游戏，用户量超过3亿。

Notcoin，这是点击挖矿类的应用，用户量3500万以上。

Catizen、Yescoin、TapSwap，这些也都是游戏类的，用户量都在数千万级别。

Mini Apps的开发优势很明显：可以触达Telegram的9亿用户；不用安装，即点即用；内置支付和钱包集成；还有病毒式传播的能力。

### Toncoin代币经济

最后说说Toncoin，也就是TON代币。

Toncoin是TON区块链的原生代币，代币符号是TON。总供应量大约50亿个，每年有0.5%到1%的通胀，用于奖励验证者。

Toncoin有几个主要用途：

第一，Gas费用。执行交易和智能合约需要支付TON。

第二，质押。验证者需要质押TON才能参与共识，普通用户也可以委托质押。

第三，存储费用。智能合约的数据存储需要支付TON。

第四，治理。未来可能会用于协议治理投票。

## 第三部分：开发环境搭建

好了，了解了TON的基本情况和生态，如果你也想开始开发，我们需要先搭建开发环境。

### Node.js安装

TON的开发工具主要基于Node.js，所以首先需要安装Node.js。

系统要求是Node.js v22.0.0或更高版本，npm v10.0.0或更高版本。

Windows用户可以直接访问nodejs.org下载LTS版本，然后按提示安装。

macOS用户可以用Homebrew安装，命令是brew install node at 22。

Linux用户可以用NodeSource安装，具体命令教材里有详细说明。

安装完成后，用node --version和npm --version验证一下版本。

### Blueprint框架安装

Blueprint是TON官方推荐的合约开发框架，提供项目模板、编译、测试和部署的一站式解决方案。

安装很简单，用npx create-ton at latest，后面加上你的项目名称。创建项目时会问你几个问题：项目名称、选择模板（推荐选Tact language）、是否初始化Git仓库。

项目创建好后，进入目录，运行npm install安装依赖。

Blueprint项目的结构是这样的：

contracts文件夹放合约源代码；tests文件夹放测试文件；scripts文件夹放部署脚本；wrappers文件夹放合约包装器；build文件夹放编译输出；还有一些配置文件。

常用的命令有：

npx blueprint build编译合约；

npx blueprint test运行测试；

npx blueprint run --testnet部署到测试网；

npx blueprint run --mainnet部署到主网；

npx blueprint create加上合约名可以创建新合约。

### Acton工具安装

Acton是TON官方的新一代开发工具链，还在发展中。

安装命令是npm install -g at ton-community/acton。

Acton和Blueprint相比，Acton是官方工具，Blueprint是社区框架。Blueprint更成熟，推荐新手从Blueprint开始。

### VS Code配置

Visual Studio Code是TON开发的首选IDE。

推荐安装几个插件：Tact插件用于Tact语言支持；Tolk插件用于Tolk语言支持；ESLint用于代码检查；Prettier用于代码格式化；GitLens用于Git增强。

还可以配置一些设置，比如保存时自动格式化，排除node_modules等文件夹。

### 测试网配置

在部署到主网之前，必须在测试网进行充分测试。

测试网使用没有实际价值的测试币。获取测试网TON有几种方式：

最常用的是官方水龙头，在Telegram里搜索at testgiver_ton_bot，发送start命令，按提示完成验证，提供你的测试网钱包地址，每次可以获得2个测试网TON。

配置测试网钱包，推荐用Tonkeeper。下载应用后，进入设置，网络，切换到Testnet，然后复制测试网地址去水龙头领币。

测试网的区块链浏览器有TON Scan Testnet、TON Viewer、Dton等。

### 主网准备

当合约在测试网验证通过后，可以准备部署到主网。

安全建议：使用硬件钱包，比如Ledger；重要合约使用多签钱包管理；首次部署先用小额资金测试；安全备份钱包助记词。

获取主网TON可以通过交易所购买，Binance、OKX、Bybit等主要交易所都支持TON。部署合约需要支付Gas费用，建议准备至少0.5到1个TON。
