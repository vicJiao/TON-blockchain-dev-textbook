## 第一部分：开发工具概述

首先，我们来整体了解一下TON开发需要哪些工具。

开发TON智能合约，主要需要这么几类工具：

第一类是编程语言环境。TON智能合约主要用FunC语言编写，而开发工具大多基于JavaScript或TypeScript。所以我们需要Node.js环境。

第二类是开发框架。框架就像是脚手架，帮我们快速搭建项目结构，提供编译、测试、部署等功能的封装。目前TON生态最流行的框架是BluePrint。

第三类是代码编辑器。写代码当然需要一个顺手的编辑器，我们推荐使用VS Code，它有很好的FunC语法高亮和调试支持。

第四类是钱包和浏览器。部署合约需要用到钱包来支付Gas费，查看合约状态需要用到区块链浏览器。

第五类是其他辅助工具。比如代码格式化工具、静态分析工具、API客户端等等。

这些工具组合在一起，就构成了完整的TON开发工具链。接下来，我们会逐一安装和配置这些工具。

## 第二部分：Node.js环境配置

好，我们从最基础的Node.js开始。

Node.js是一个JavaScript运行时环境，让我们的电脑可以执行JavaScript代码。TON的开发工具大多是用JavaScript编写的，所以Node.js是必须的。

首先，我们需要检查电脑上是否已经安装了Node.js。打开命令行工具，输入node -v，如果显示版本号，说明已经安装了。如果提示命令找不到，那就需要安装。

安装Node.js很简单。去Node.js的官网nodejs.org，下载LTS版本。LTS是长期支持版本，比较稳定，适合开发使用。下载安装包后，一路点击下一步就可以了。

安装完成后，再次在命令行输入node -v，应该能看到版本号，比如v18.17.0之类的。同时输入npm -v，npm是Node.js的包管理器，也应该能看到版本号。

Node.js安装好了，我们还需要配置一下npm的镜像源。因为npm默认的服务器在国外，国内访问可能会比较慢。我们可以把镜像源换成国内的，比如淘宝镜像或者腾讯云镜像。

配置镜像源的命令是：npm config set registry https://registry.npmmirror.com

配置完成后，npm下载包就会快很多。

另外，建议安装一个Node.js版本管理工具，比如nvm。因为不同的项目可能需要不同版本的Node.js，有了nvm就可以轻松切换版本。安装nvm的方法可以去它的GitHub仓库查看，有详细的说明。

Node.js环境就配置好了，这是后续所有工具的基础。

## 第三部分：BluePrint框架安装

接下来，我们安装TON开发的核心框架——BluePrint。

BluePrint是TON基金会官方推荐的开发框架，它提供了一整套开发智能合约的工具链。用BluePrint，我们可以快速创建项目、编译合约、运行测试、部署到网络。

BluePrint的设计理念是让TON开发变得简单。它封装了很多底层细节，让我们可以专注于业务逻辑，不用操心那些繁琐的配置。

安装BluePrint很简单，只需要一个npm命令：npm install -g @ton-community/blueprint

这个-g参数表示全局安装，安装完成后，在任意目录都可以使用blueprint命令。

安装完成后，输入blueprint -v检查一下版本。如果显示版本号，说明安装成功了。

现在我们可以用BluePrint创建一个新项目了。执行blueprint create my-project，这里的my-project是项目名，你可以改成自己喜欢的名字。

BluePrint会问你几个问题，比如选择合约模板、是否安装依赖等。对于初学者，建议选择简单的模板，比如empty或者counter。依赖建议选择安装，这样项目创建完就能直接用了。

项目创建完成后，进入项目目录，你会看到这样一个结构：

contracts文件夹，存放FunC合约代码；
wrappers文件夹，存放TypeScript包装器代码；
tests文件夹，存放测试代码；
scripts文件夹，存放部署脚本；
还有一些配置文件。

这个结构是BluePrint推荐的标准项目结构，遵循这个结构，你的项目会更容易维护，也更容易被其他开发者理解。

在项目目录下运行npm install，安装项目依赖。依赖安装完成后，运行npm run build，如果一切正常，说明环境配置成功了。

## 第四部分：VS Code配置

好，开发框架装好了，接下来我们配置代码编辑器。

我们推荐使用VS Code，它是目前最流行的代码编辑器，免费、开源、插件丰富。对于TON开发，VS Code有专门的插件支持。

首先，去VS Code官网下载安装包，安装过程很简单，就不多说了。

安装完成后，我们需要安装几个对TON开发很有帮助的插件。

第一个是FunC插件，它提供FunC语言的语法高亮、代码补全、错误检查等功能。在VS Code的扩展商店搜索"FunC"，应该能找到由ton-community提供的官方插件。

第二个是Tact插件。虽然我们主要学FunC，但了解一下Tact语言也有好处。Tact是TON生态中另一种智能合约语言，语法更接近TypeScript。

第三个是ESLint和Prettier插件。这两个是JavaScript/TypeScript开发的标配，一个负责代码质量检查，一个负责代码格式化。保持代码风格一致，对团队协作很重要。

第四个是GitLens插件。如果你用Git管理代码，这个插件可以提供强大的Git功能，比如查看代码历史、比较版本差异等。

安装完插件后，我们还需要配置一些VS Code的设置。打开设置，搜索format on save，勾选这个选项。这样每次保存文件时，VS Code会自动格式化代码，保持代码整洁。

再搜索tab size，把缩进设置为4个空格。这是FunC代码的推荐缩进。

VS Code的配置就完成了。现在打开我们刚才用BluePrint创建的项目，你应该能看到FunC代码有漂亮的语法高亮了。

## 第五部分：测试网配置

环境搭好了，接下来我们要配置网络环境。开发智能合约，通常先在测试网上测试，没问题了再部署到主网。

测试网是什么？你可以把它理解为区块链的"沙盒环境"。测试网上的代币没有真实价值，可以随意获取，用来测试合约功能。测试网和主网的代码逻辑是一样的，只是网络不同。

首先，我们需要一个测试网钱包。推荐使用TON Keeper钱包，它是TON生态最流行的钱包之一。

下载安装TON Keeper后，创建一个新钱包。在钱包设置里，把网络切换到测试网。TON Keeper支持同时管理主网和测试网的钱包，很方便。

有了钱包，我们还需要测试币。测试币可以通过水龙头免费获取。去TON的测试网水龙头网站，输入你的测试网钱包地址，就能领取测试币。通常一次能领几个TON，足够开发测试用了。

接下来，我们需要在BluePrint项目中配置测试网。打开项目目录下的blueprint.config.ts文件，这里可以配置网络参数。

默认配置通常已经包含了测试网的设置，你只需要确认一下RPC端点的地址。测试网的RPC地址通常是https://testnet.toncenter.com/api/v2/jsonRPC之类的。

配置完成后，我们可以写一个简单的脚本来测试连接。在scripts文件夹下创建一个test-connection.ts文件，写几行代码获取测试网的最新区块高度。如果能成功获取，说明测试网配置正确。

## 第六部分：主网准备

测试网配置好了，我们再来说说主网的准备。

主网是TON的真正网络，上面的代币有真实价值，操作需要谨慎。在部署到主网之前，你需要确保合约在测试网上经过了充分测试。

主网的配置和测试网类似，只是网络参数不同。主网的RPC端点通常是https://toncenter.com/api/v2/jsonRPC。

主网部署需要真实TON代币作为Gas费。你可以从交易所购买TON，然后提现到你的钱包地址。

这里要特别提醒几点：

第一，主网操作不可逆。一旦合约部署到主网，就无法修改。如果合约有漏洞，可能会造成资金损失。所以务必在测试网上充分测试。

第二，保管好私钥。主网钱包的私钥一旦泄露，资产就可能被盗。建议使用硬件钱包，或者把私钥离线保存。

第三，注意Gas费。主网的Gas费虽然不高，但复杂操作也会消耗不少TON。部署前先用工具估算一下Gas费，确保钱包里有足够的余额。

第四，考虑使用多签钱包。如果是团队项目，建议使用多签钱包管理资金，避免单点风险。

## 第七部分：其他开发工具

最后，我们再介绍几个有用的开发工具。

第一个是TON Scan区块链浏览器。浏览器可以查看区块链上的所有交易、合约、账户信息。TON Scan是官方推荐的浏览器，界面清晰，功能强大。开发过程中经常需要用到它来调试和验证。

第二个是Toncenter API。这是一个提供区块链数据查询服务的API，很多DApp都依赖它来获取链上数据。BluePrint默认就集成了Toncenter的客户端。

第三个是Fift调试器。Fift是TON的汇编语言，有时候我们需要看合约编译后的Fift代码来调试。TON提供了Fift解释器，可以在本地运行。

第四个是合约分析工具。比如Tonalytica，可以分析合约的安全性，检查常见的漏洞。在部署重要合约之前，建议先用这类工具扫描一下。

第五个是文档和示例代码。TON官方文档非常详细，遇到问题时先去查文档。GitHub上也有很多开源项目可以参考学习。
